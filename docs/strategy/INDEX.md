# Strategy Authority Index

This index prevents dated strategy snapshots from silently competing for authority.

## Authority

1. `ARCHITECTURE.md` — canonical architecture and current proof boundary.
2. `ARCHITECTURE-FINALIZATION-TRACK-2026-08-29.md` — active architecture-finalization work until explicitly closed.
3. `ARCHITECTURE-AUDIT-V2-HARDENING-2026-08-28.md` — audit findings and durable implementation evidence.
4. `PROJECT-PROGRESS-SNAPSHOT-POST-LUMEN-LEARNING-2026-08-28.md` — canonical project-progress snapshot for its role.

Machine-readable status and supersedes links live in `STATUS-CHAIN.json`.

Any strategy document not listed there as `canonical`, `active-track`, or `active-evidence` is historical/non-authoritative by default. A dated snapshot may remain valuable evidence without becoming current architectural authority.

`PROJECT-PROGRESS-SNAPSHOT-S0-S5-CLOSED-2026-08-28.md` is explicitly superseded for project-progress status by the post-Lumen snapshot; it remains historical evidence of the earlier checkpoint.
