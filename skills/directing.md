# Directing — learned directives for the Creative Director role.
# Post-mortems append rules here. Owner may edit freely.

- Prefer mechanics where ANY random input quickly produces score progress; the machine playtester mashes keys and clicks randomly, and the contract requires measurable score growth within ~15 seconds.
- The first 10 seconds of gameplay must already show the core action. No long intros, no unskippable tutorials beyond one line of text.
- Keep arenas single-screen (960x540) unless the mechanic truly needs scrolling; scrolling adds verification risk.
- Design at least one "signature moment" per game (a specific juicy interaction a player would remember).
